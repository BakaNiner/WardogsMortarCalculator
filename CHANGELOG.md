# 更新记录 / Changelog

## 1.1.0

- 添加完整英文界面，设置旁的地球图标可即时切换中英文，并记住语言选择。 / Added an English interface with an instant language toggle beside Settings and a saved language preference.
- 切换语言时保留坐标输入、识别预览及后台任务。 / Language changes preserve coordinate inputs, capture previews, and background jobs.
- 提高提示音复选框选中状态的辨识度。 / Made the selected state of the sound checkbox easier to see.
- 悬浮窗不透明度支持实时预览及百分比显示，取消时恢复原值和显示状态。 / Added live overlay-opacity preview and a percentage display, with Cancel restoring previous opacity and visibility.
- README 改为中英双语，注明由 GPT-6 Astra 生成；新增发布打包脚本、版本 ZIP 及 SHA-256 校验文件。 / Added a bilingual README crediting GPT-6 Astra, a release-packaging script, versioned ZIPs, and SHA-256 checksums.
- 将本地截图排除在后续提交和程序包外，移除开发测试代码及其专用依赖。 / Excluded local screenshots from future commits and application packages, and removed development test code and its dedicated dependencies.

## 1.0.0

- 首个 Windows 桌面版本：全局快捷键截图、本地 OCR、手动坐标输入、地图区域校准及置顶悬浮窗。 / Initial Windows desktop version with global capture hotkeys, local OCR, manual coordinate entry, map-region calibration, and an always-on-top overlay.
- 使用 L81 社区平地射表，计算方位角、水平距离和 MIL。 / Calculates azimuth, horizontal distance, and MIL using the community L81 flat-ground firing table.
